## Frontend Frameworks

- [https://nextjs.org/](https://nextjs.org/) → fullstack React framework with SSR and routing
    
- [https://reactjs.org/](https://reactjs.org/) → core React library for building UI components
    
- [https://svelte.dev/](https://svelte.dev/) → lightweight reactive JS framework
    
- [https://astro.build/](https://astro.build/) → static site generator with component islands
    

## Backend Frameworks

- [https://nestjs.com/](https://nestjs.com/) → structured Node.js backend framework (TypeScript-first)
    
- [https://fastify.dev/](https://fastify.dev/) → fast and low-overhead Node.js web framework
    
- [https://flask.palletsprojects.com/](https://flask.palletsprojects.com/) → lightweight Python web framework
    

## UI / Styling

- [https://tailwindcss.com/](https://tailwindcss.com/) → utility-first CSS framework
    
- [https://picocss.com/](https://picocss.com/) → minimal CSS framework for semantic HTML
    
- [https://ui.shadcn.com/](https://ui.shadcn.com/) → copy-paste React UI components with Tailwind
    
- [https://ant.design/](https://ant.design/) → enterprise-grade React UI components
    
- [https://mui.com/](https://mui.com/) → Material Design React components
    

## Backend / Database

- [https://supabase.com/](https://supabase.com/) → open-source Firebase alternative (Postgres + auth + storage)
    
- [https://planetscale.com/](https://planetscale.com/) → serverless MySQL platform with branching
    
- [https://pocketbase.io/](https://pocketbase.io/) → lightweight backend (DB + auth) in a single binary
    

## Deployment / Hosting

- [https://vercel.com/](https://vercel.com/) → deploy frontend and fullstack apps easily
    
- [https://www.netlify.com/](https://www.netlify.com/) → static site hosting with CI/CD and edge functions
    
- [https://render.com/](https://render.com/) → deploy backend services and databases easily
    
- [https://railway.app/](https://railway.app/) → simple infra + database setup
    

## Cloud / Platform

- [https://aws.amazon.com/](https://aws.amazon.com/) → cloud computing platform with scalable infrastructure
    
- [https://cloud.google.com/](https://cloud.google.com/) → GCP services for compute, storage, and AI
    
- [https://azure.microsoft.com/](https://azure.microsoft.com/) → Microsoft cloud platform
    
- [https://www.digitalocean.com/](https://www.digitalocean.com/) → simple cloud hosting and VPS
    
- [https://www.cloudflare.com/](https://www.cloudflare.com/) → CDN, DNS, edge compute, and security
    

## Web Server / Networking

- [https://nginx.org/](https://nginx.org/) → high-performance web server and reverse proxy
    
- [https://caddyserver.com/](https://caddyserver.com/) → web server with automatic HTTPS
    
- [https://ngrok.com/](https://ngrok.com/) → expose localhost to the internet
    
- [https://traefik.io/](https://traefik.io/) → modern reverse proxy and load balancer
    

## Containers / DevOps

- [https://www.docker.com/](https://www.docker.com/) → containerize applications for consistent environments
    
- [https://podman.io/](https://podman.io/) → daemonless container engine (Docker alternative)
    
- [https://kubernetes.io/](https://kubernetes.io/) → orchestrate and scale containerized applications

- [https://www.exploit-db.com/](https://www.exploit-db.com/) → public database of exploits and vulnerabilities
